# hikap

Toolkit-agnostic hiccup component engine and component runtime, built on the
standalone reakt reactive engine.

## Tests

    bb test
    jolt test

The JVM suite uses `clojure -M:test`; the `:test` alias points at the sibling
`../reakt` checkout.
